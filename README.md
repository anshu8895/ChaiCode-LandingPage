# ChaiCode - Home for Programmers

![ChaiCode](./src/assets/chaicode-white.svg)

## About ChaiCode

ChaiCode is a comprehensive platform for coding education, featuring cohort-based learning, peer coding reviews, virtual coding hostels, and a supportive community. The platform offers various courses on modern web development, data science, DevOps, and emerging technologies.

## Features

### 🌟 Key Sections

- **Hero Section**: Features "Consistency and Community" with a focus on our unmatched learning experience
- **Tweet Love**: Real testimonials from our coding community members
- **Technology Cloud**: Interactive display of programming technologies taught
- **Cohorts**: Information about our structured learning programs
- **Udemy Courses**: Integration with Udemy platform courses
- **Alumni Network**: Connection platform for students with job opportunities
- **Benefits**: Key advantages of choosing ChaiCode for learning
- **Free Resources**: Access to free APIs, documentation, and tools
- **Mobile App**: Cross-platform mobile application for learning on the go
- **Discord Community**: Active developer community with 80,000+ members
- **YouTube Channels**: Free educational content across multiple channels

### 🚀 Website Features

- Responsive design optimized for all devices
- Dark theme with modern UI components
- Interactive animations and transitions
- Back to Top button for easy navigation
- Social media integration
- Yellow-accented design system

## 🛠️ Technologies Used

- **Framework**: React with Vite
- **Styling**: TailwindCSS
- **Animations**: Custom CSS animations & Canvas animations
- **Icons**: SVG icons
- **Build Tool**: Vite
- **Deployment**: Vercel

## 📋 Installation

1. Clone the repository
   ```bash
   git clone https://github.com/anshu8895/ChaiCode-LandingPage.git
   cd my-app
   ```

2. Install dependencies
   ```bash
   npm install
   ```

3. Start the development server
   ```bash
   npm run dev
   ```

## 🖥️ Usage

After starting the development server, the application will be available at `http://localhost:5173/`.

### Key Components

- `Hero.jsx` - Main landing section
- `TopicsCloud.jsx` - Interactive technology cloud with animations
- `AlumniNetwork.jsx` - Alumni network visualization with animated connections
- `Footer.jsx` - Site footer with navigation and social links

## 🎨 Design System

The ChaiCode platform uses a consistent design system:

- **Primary Colors**: Black background with yellow/amber accents
- **Typography**: Modern sans-serif font stack
- **Components**: Cards, buttons, and interactive elements with hover states
- **Animations**: Pulse, float, and shimmer effects throughout the interface
